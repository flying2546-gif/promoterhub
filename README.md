# PromoterHub 🚀

แพลตฟอร์มศูนย์กลางสำหรับการโปรโมทเกม โฆษณาทั่วไป และแคมเปญการตลาด

## 📋 โครงสร้างโปรเจค

```
promoterhub/
├── frontend/                 # React Application
│   ├── src/
│   │   ├── components/      # UI Components
│   │   ├── pages/           # Page Components
│   │   ├── styles/          # Tailwind CSS
│   │   ├── hooks/           # Custom Hooks
│   │   └── App.jsx
│   ├── package.json
│   └── vite.config.js
├── backend/                 # Node.js + Express API
│   ├── src/
│   │   ├── routes/          # API Routes
│   │   ├── models/          # Database Models
│   │   ├── controllers/     # Business Logic
│   │   ├── middleware/      # Custom Middleware
│   │   └── server.js
│   ├── package.json
│   └── .env.example
├── database/                # Database Schema
│   └── schema.sql
└── docs/                    # Documentation
```

## 🎯 ฟีเจอร์หลัก

- ✅ Dashboard พร้อม Banner Carousel
- ✅ Category Grid Filter (Games, General Ads, Trending)
- ✅ Promotion Cards
- ✅ Admin Panel (CRUD Operations)
- ✅ Dynamic Filtering
- ✅ Analytics Tracking
- ✅ Responsive Design

## 🛠️ เทคโนโลยี

- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: PostgreSQL / SQLite
- **Analytics**: Click Tracking

## 📱 Responsive

- Desktop (1920px+)
- Tablet (768px - 1024px)
- Mobile (< 768px)

## 🚀 Quick Start

```bash
# Frontend
cd frontend && npm install && npm run dev

# Backend
cd backend && npm install && npm run dev
```
